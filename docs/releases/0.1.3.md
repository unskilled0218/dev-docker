## Fixes

- Include parsed numeric HTTP status codes in release transport and caller-level status refusals without exposing credentials or sensitive request/response data.
- Preserve the existing accepted responses, registry challenge/absence behavior, refusal exception types, and publication/retry safeguards.
- Add offline diagnostic, privacy, and zero-write startup regressions.

## Verification limits

This is a diagnostic-only fix, not a repair of server permissions or a production release claim. Real builds, publication, and live package visibility require separate authorization and verification. Repeated Bash error-handler output is unchanged.
