# Release v0.1.13

- [Release v0.1.13](#release-v0113)
  - [Changes](#changes)

## Changes

- Add a standalone official Playwright 1.64.1 browser server on the shared development network, with bounded WebSocket readiness checks.
- Keep only the matching Playwright client in the npm image; remove local browser and browser-library installation.
- Document independent clients, startup failure handling, and remote application addressing.
- Remove the automatic OpenCode server command and default server password from base, and remove its Compose host port mapping. The external setup script remains in place.
