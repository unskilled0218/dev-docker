## Changes

- Reject malformed existing JSONC before merging Penpot defaults, preserving original bytes and directory contents on refusal.
- Separate string-aware comment removal from one guarded trailing-comma pass, preventing double commas and missing values from being silently repaired.
- Add malformed-input, valid-JSONC, and sanitized CLI regressions while preserving token handling and atomic writes.
