# Release v0.1.22

- [Release v0.1.22](#release-v0122)
  - [Changes](#changes)

## Changes

- Add container-user-owned Penpot MCP defaults to base and npm images, using runtime token-file substitution rather than embedded credentials.
- Replace the individual Compose Git token mount with one read-only `~/.config/token` directory containing `git` and `penpot`.
- Move Git's default input and BuildKit secret target to the shared layout while preserving explicit credential overrides and secret ID `token`.
- Add a Python 3 config merger with JSON/JSONC settings preservation, safe failure handling, and isolated tests; include its source in both build snapshot modes.
- Document token migration, plugin connection, and verification limits.
