# Release v0.1.2

- [Changes](#changes)
- [Verification limits](#verification-limits)

## Changes

- Build and release only `base` and `npm`, retaining version and `latest` aliases.
- Exclude Android, Tauri, and Switchboard from automated builds and publication; retain their Dockerfiles for manual use.
- Associate released container packages with `dev/dev-docker` after verifying the authenticated namespace owner, repository access, and package evidence.
- Support the characterized Gitea `1.24.7` and `28.2.0` package contracts; refuse unknown versions, ambiguous reads, foreign links, or hidden identity evidence without reassignment.

## Verification limits

Offline verification does not certify native Docker builds or live publication. Repository Packages-page visibility requires separately authorized publication and inspection. Existing packages and historical tags are not migrated or deleted.
