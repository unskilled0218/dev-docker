## Changes

- Copy `penpot.lanCA.crt` alongside Git and ntfy CA certificates before updating base image trust; npm inherits that trust.
- Require `penpot_certificate_file`, defaulting to `/usr/local/share/ca-certificates/penpot.lanCA.crt`, with the `BUILD_PENPOT_CERT_FILE` override in both automated build modes.
- Include all three captured certificates in snapshots, release fingerprints, and publication guards while preserving certificate-free offline validation.
- Extend isolated tests for input failures, overrides, snapshots, fingerprints, and Dockerfile ordering. Certificates remain externally supplied and are never downloaded or committed.
