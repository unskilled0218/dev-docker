# Release v0.1.0

- [Changes](#changes)

## Changes

- Introduce one versioned release for all five AMD64 development images, including Switchboard.
- Build release children from verified parent digests and publish guarded version/latest aliases with an identity-bound Git tag and notes-only Gitea release.
- Add offline validation, explicit settings, isolated credentials, and safe refusal of ambiguous publication states.
- Preserve local build-only tags, legacy credential overrides, and matching positional version assertions.
- Native Docker/Buildx readiness remains unverified until the separately authorized smoke checklist passes. No production publication is implied by offline verification.
